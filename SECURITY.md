# Security Policy

Please report security vulnerabilities privately, not in a public issue.

- **Preferred:** [report a vulnerability](https://github.com/Analytically-ai/truequery/security/advisories/new)
  through GitHub's private reporting.
- **Or email** hello@analytically.ai with "Security" in the subject.

Include what you found, how to reproduce it, and the version
(`truequery --version`). We'll acknowledge your report, keep you updated,
and credit you in the fix unless you'd rather we didn't.

Only the latest release is supported with security fixes.

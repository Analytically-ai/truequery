# DATA.md — TrueQuery project context

Stack: plain · Dialect: sqlite · Generated by `tq init` — edit freely, but keep the tq-config block.

Source: `financial.sqlite`, the PKDD'99 / BIRD "financial" dataset (a Czech
bank, 1993–1998). Static snapshot. Column notes are in `database_description/`,
but its currency and date-format notes are wrong (see below). Contracts for
all 8 tables are in `contracts/`.

## Owners, layers, SLAs

- Owner of corrections: the project owner (sole owner of the data, contracts and definitions; confirmed 2026-10-25)
- PII masking: none needed. This is a public benchmark dataset (owner, 2026-10-25).
- Layers: one raw layer only (the SQLite file). No staging or marts yet.
- Freshness: none. The snapshot ends 1998-12-31 and never refreshes.

## House definitions (from the init interview, 2026-10-25)

- **Headline metric:** none pinned yet. Every analysis names its own metric
  and the SQL that defines it. Run `/truequery metric` to pin one later.
- **Test / internal accounts:** none. All 4,500 accounts and 5,369 clients
  count. Nothing in the data marks test or internal accounts.
- **Money:** CZK (Czech crowns), whole major units, not cents.
  `trans.amount`, `trans.balance` and `loan.amount` are integers;
  `order.amount` and `loan.payments` are reals. `database_description/`
  says USD, which is wrong for this dataset.
- **Business dates:** each table uses its own native date.
  - transactions: `trans.date` (posting date)
  - loans: `loan.date` (approval date)
  - accounts: `account.date` (open date)
  - cards: `card.issued`
  - orders: no date, so they can't be put on a timeline
  - "Today" / as-of = 1998-12-31 (last `trans.date`)

## Conventions every query must respect (verified against the data, 2026-10-25)

- Dates are ISO `YYYY-MM-DD` TEXT. The descriptions say YYMMDD; that's wrong.
  Filter with string ranges or `strftime`.
- Transaction sign comes from `trans.type`. `amount` is never negative.
  - `PRIJEM` = credit (+)
  - `VYDAJ` = debit (−)
  - `VYBER` = debit (−), undocumented, 16,666 rows. Balance deltas show
    it's a withdrawal. Never treat "not PRIJEM" as a missing value.
- "No symbol" in `trans.k_symbol` has two spellings: NULL and `' '`
  (one space). In `order.k_symbol` it's `''` (empty string).
- `account` → `disp` fans out (869 accounts also have a DISPONENT).
  Filter `disp.type = 'OWNER'` to keep one row per account.
- `order` is a reserved word. Quote it: `` `order` `` or `"order"`.
- `district.A4`–`A7` are numbers stored as TEXT. CAST before doing math
  or sorting.

## Open definitions (not yet decided)

- Bad loan: deliberately left undefined (owner, 2026-10-25). Common usage
  is `loan.status IN ('B','D')`. If a question needs it, state the reading
  you used, or ask.
